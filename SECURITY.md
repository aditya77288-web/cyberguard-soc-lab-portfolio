# Security Policy

## Project Scope

CyberGuard SOC Lab is an educational SOC dashboard simulation. It uses synthetic security telemetry and simulated workflows. It is not a production SIEM or a real-world incident response platform.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately through GitHub's **Report a vulnerability** feature, if available.

Please include:
- A clear description of the issue.
- Steps to reproduce it.
- Potential security impact.
- Relevant screenshots or proof of concept, if safe to provide.

Please do not publish sensitive vulnerability details in a public issue before the problem has been reviewed.

## Supported Versions

Security reports are accepted for the latest version available on the `main` branch.

## Responsible Disclosure

Please allow reasonable time for the issue to be reviewed before publicly disclosing it.
